THE LISTENING EXPERIENCE

简单，刚好够用。

从扫描曲库到锁屏控制，每个细节都围绕一件事：让你更自在地听自己的音乐。

01 / LIBRARY

你的本地曲库

扫描手机音乐，也可授权文件夹。歌曲、专辑、歌手与文件夹，按你熟悉的方式浏览。

02 / PLAYBACK

一路播放，不被打断

后台播放、通知栏与锁屏控制都已就位；拔下耳机，音乐自动暂停。

03 / COLLECTION

收藏与歌单

把喜欢的歌收好，建立自己的歌单，随时从最近播放继续。

04 / LYRICS

歌词跟着歌曲走

读取同目录 LRC 歌词，在全屏播放页里安静地看词、听歌。

05 / COLOR

封面带来色彩

从当前专辑封面提取色调，让播放页背景随音乐自然变化。

06 / PRIVATE

音乐只留在手机里

无需账号和网络；应用不申请互联网权限，也没有广告。
